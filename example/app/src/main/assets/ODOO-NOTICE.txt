Odoo client — independent Android example

This example imports the compiled Kotlin adaptation of the Python Odoo Client
Library version 2.0.1, originally published by Odoo:
https://github.com/odoo/odoo-client-lib

Android/Kotlin adaptation maintained by elierwclik:
https://github.com/elierwclik
Adaptation repository: https://github.com/elierwclik/odoo-client-lib
Official server repository (reference): https://github.com/odoo/odoo
No original Python source files are bundled with this example.
